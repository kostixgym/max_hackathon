Журнал реализации. После каждого шага здесь появляется отчёт: что сделано в коде, какие решения приняты и почему,
как проверено и что осталось. Шаги маленькие, чтобы их было удобно ревьюить.
План этапов — в [../05-plan-realizacii.md](../05-plan-realizacii.md), сводка «что сделано и что дальше» — в [../status.md](../status.md).
