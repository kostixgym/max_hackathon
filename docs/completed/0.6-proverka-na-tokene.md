# Шаг 0.6. Проверка на настоящем токене MAX (бот)

Дата: 26.09.2026. Статус: часть про бота проверена. Часть про мини-приложение ждёт шага 0.4 и сервера.

Бот `@t603_hakaton_max_bot` («Хакатон МАХ 603», профиль задали организаторы) запущен локально через `docker compose`
с настоящим токеном. Проверки шли в MAX с одного аккаунта.

## Проверено

| Что | Результат |
|---|---|
| Подключение к API MAX | Сначала не работало: `x509: certificate signed by unknown authority`. Сертификат `platform-api2.max.ru` выпущен национальным УЦ Минцифры (`*.max.ru` ← Russian Trusted Sub CA ← Russian Trusted Root CA). Этого корня нет ни в образе, ни в macOS. **Исправлено:** корень взят с Госуслуг, цепочка `max.ru` сверена с ним (`openssl verify`), он встроен в бэкенд, и ему доверяет только клиент MAX (`maxbot.HTTPClient`). Отпечаток закреплён в тесте |
| `GET /me`, запуск бота | Работает; вебхуков нет, long polling получает события |
| Ссылка дома `max.ru/<бот>?start=<slug>` | Приходит `bot_started` со ссылкой в `payload`, бот отвечает приветствием демо-дома с кнопкой «Открыть приложение» |
| Перезапуск бота | Позиция в ленте событий сохраняется в БД, повторного приветствия нет |
| Приглашение в опрос | Задача очереди выполнена с первой попытки. В сообщении есть срок по времени дома («до 3 октября, 13:18») и кнопки «Поддерживаю / Против / Есть вопрос / Открыть приложение» |
| Нажатие «Поддерживаю» или «Против» | Голос записан с весом из снимка (63,50 м², кв. 12). `POST /answers` с полем `message` **переписывает само сообщение**: «Ваш голос: «против», 63,50 м²…», кнопки остаются (решение 68 работает) |
| `/id` в режиме разработки | Бот присылает MAX id. Через `X-Dev-User-Id` с этим id можно действовать в API от имени настоящего аккаунта, пока нет мини-приложения |

## Находки

- **Всплывающее уведомление из `POST /answers` в клиенте не видно.** Ответ с одним полем `notification`
  («Есть вопрос») API принимает без ошибки, но пользователь ничего не видит. Поэтому видимая реакция должна идти через
  обновление сообщения или новое сообщение. «Есть вопрос» переделаем вместе с дизайном сообщения опроса.
- **Дизайн сообщения опроса.** Строка с текущим голосом теряется в тексте, изменение слабо заметно. Нужна другая
  структура сообщения, решим отдельно.
- **Кнопка «Открыть приложение» ничего не делает.** В настройках бота на платформе MAX не задан адрес мини-приложения,
  и само мини-приложение не выложено по HTTPS. Нужны шаг 0.4 и сервер.
- **В API `platform-api2` нет списка чатов** (`GET /chats` → 404). Узнать id пользователя можно только из событий,
  отсюда команда `/id` для разработки.
- **Профиль бота:** ник `t603_hakaton_max_bot` через API не меняется. Имя, описание, аватар и меню команд меняются
  через `PATCH /me`, когда выберем название продукта.

## Не проверено (нужны мини-приложение и сервер)

- `requestContact`: номер телефона для сверки с реестром.
- `chat.id` в `initData` при запуске из группового чата.
- Сканер QR в веб-версии.
- Лимиты API на массовой рассылке.
- Запуск на мобильном клиенте. Все проверки выше шли на десктопе.
