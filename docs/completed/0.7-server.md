## Что сделано

- **Сервер:** VPS `45.154.58.251` (Ubuntu 26.04, 1 CPU, 2 ГБ, диск 30 ГБ). Проект — в `/opt/max_hackathon`,
  запускается через `docker compose`: база, бэкенд и Caddy.
- **HTTPS на временном домене `45-154-58-251.sslip.io`.** Сервис sslip.io сам указывает такое имя на IP из него,
  поэтому покупать домен и настраивать DNS не пришлось.
  - Caddy получает сертификат Let's Encrypt и продлевает его сам, сертификаты хранятся в томе `caddy-data`.
  - HTTP перенаправляется на HTTPS, порт 8080 закрыт.
- **Прод-`.env`** (права 600, в git не попадает):
  - `SITE_ADDRESS=45-154-58-251.sslip.io`, `HTTP_PORT=80`, `HTTPS_PORT=443`;
  - `DEV_MODE=false`;
  - токен бота.

  Прежний файл сохранён рядом как `.env.bak-20260927125438`.
- **Бот работает только на сервере.** Токен у команды один, а два запущенных экземпляра перехватывают друг у друга
  сообщения. Поэтому локально — `DEV_MODE` и пустой `MAX_BOT_TOKEN`.
- **Доступ к репозиторию.** Репозиторий приватный: сервер забирает код по SSH с deploy-ключом только на чтение
  (`/root/.ssh/github_deploy`, задан в `core.sshCommand` клона). Отозвать ключ — Settings → Deploy keys.
- **Выкачен `main`** с PR #7–#9 (`6477ebf`).

## Как обновить сервер

```
ssh root@45.154.58.251
cd /opt/max_hackathon && git pull --ff-only && docker compose up --build -d
```

Сборка на одном ядре занимает 2–4 минуты, всё это время работает старая версия. Миграции применяются при старте.

## Как проверить

- `https://45-154-58-251.sslip.io/api/v1/readyz` → `{"status":"ready"}`;
- `http://45-154-58-251.sslip.io/` → `308` на HTTPS;
- запрос с заголовком `X-Dev-User-Id` → `401` «Откройте приложение из MAX»: режим разработки выключен;
- в `docker compose logs app` есть `bot started` для `t603_hakaton_max_bot`.

## Что осталось

- **Адрес мини-приложения** `https://45-154-58-251.sslip.io/` — в настройках бота на business.max.ru: «Чат-боты» →
  бот → ⋮ → «Настройки». Пока по этому адресу заглушка.
- **Сборка `miniapp/` в образ web** — когда появится мини-приложение.
- **Постоянный домен** — по желанию:
  1. A-запись на `45.154.58.251`;
  2. новое имя в `SITE_ADDRESS` в `.env`;
  3. `docker compose up -d`;
  4. новый адрес в настройках бота.

## Риски

- **Вход под `root` по паролю открыт:** за первые 4 часа было около 1 150 попыток подбора. Когда все, кто заходит на
  сервер, добавят свои SSH-ключи, вход по паролю стоит выключить.
- **Swap нет, памяти 2 ГБ:** сборка мини-приложения (npm и Vite) на сервере может упереться в память.
- **На сервере нельзя подменить пользователя заголовком:** фронтенд разрабатывает локально с `DEV_MODE`, а проверяет
  через MAX.
