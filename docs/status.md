## Что работает сейчас

- **Запуск:** `docker compose up --build` поднимает базу, бэкенд и Caddy. Сборка образов в CI — 69 с при лимите 300.
  Миграции и демо-дом создаются сами.
- **Сервер** `https://45-154-58-251.sslip.io`: HTTPS от Let's Encrypt, `DEV_MODE=false`, бот работает только здесь.
  Обновление — `git pull` и `docker compose up --build -d`, подробности — в [отчёте 0.7](completed/0.7-server.md).
- **Бот `@t603_hakaton_max_bot`:**
  - приветствие по ссылке дома `max.ru/<бот>?start=<slug>`;
  - подсказка на любое сообщение;
  - в групповых чатах молчит;
  - «Есть вопрос»: вопрос уходит инициатору без имени, ответ возвращается спросившему;
  - итог опроса инициатору, когда выходит срок;
  - `/id` в режиме разработки.
- **Опрос поддержки** (проверен в MAX: 26.09 локально, 27.09 с сервера):
  1. Демо-подтверждение собственника.
  2. Инициатива по шаблону «Видеонаблюдение»: форма с проверкой полей (камеры, оплата, доступ к записям), в повестке
     избрание председателя и секретаря, затем камеры (2/3 от всех).
  3. Запуск опроса.
  4. Приглашение в чат с кнопками. Срок показан по времени дома, в тихие часы рассылка ждёт утра, в демо-доме приглашение
     получает только инициатор.
  5. Голос кнопкой или через `PUT /my-vote` с анкетой. После нажатия выбранная кнопка отмечена ✅, голос в м² выделен,
     видна поддержка к порогу 10%. После срока голоса не принимаются.
  6. Прогресс в м² с порогами 10% / кворум / 2/3.
- **API:**
  - `GET /me`, `GET /houses/{slug}`;
  - собственники квартиры, кандидаты в председатели;
  - `POST /houses/{slug}/demo-membership`;
  - `GET /templates`, `GET /templates/{code}` — шаблоны с формой;
  - `GET /houses/{houseID}/initiatives`, `POST /houses/{houseID}/initiatives`;
  - `GET /initiatives/{id}` — карточка с `allowed_actions` и «моим голосом»;
  - `POST /initiatives/{id}/start-poll`, `PUT /initiatives/{id}/my-vote`, `GET /initiatives/{id}/poll`;
  - кабинет УК: `POST /houses/{slug}/demo-staff`, `GET /orgs`, `GET /orgs/{orgID}/houses`, `orgs` в `/me`;
  - собрание: `POST /initiatives/{id}/meetings`, `GET /meetings/{id}`, `GET /meetings/{id}/tracker`,
    `POST /meetings/{id}/ballots/receive`, `PUT /ballots/{id}/decisions`, `PUT /meetings/{id}/gis-results`,
    `GET /meetings/{id}/result-preview`,
    `POST /meetings/{id}/finalize`, в демо-доме — `demo/finish-voting` и `demo/fill-ballots`;
  - требование в УК, `GET /orgs/{orgID}/demands` и оба PDF отвечают `501` до шагов Димы.

  Все запросы проверяют подпись MAX, в режиме разработки её заменяет заголовок `X-Dev-User-Id`. На сервере режим
  разработки выключен.
- **Данные и безопасность:**
  - HMAC для телефонов и лицевых счетов, маски ФИО, права на каталоги собственников;
  - точная арифметика долей;
  - итог собрания меняется только один раз;
  - лимиты: тело запроса — 64 КБ, инициатив — 10 в сутки;
  - корень УЦ Минцифры действует только для MAX.
- **CI на каждый пуш:** `gofmt`, `go vet`, тесты с `-race` на PostgreSQL 18 (пул на два соединения, лимит 5 минут),
  сборка образов.

## Решения и вопросы к команде

- **Название продукта.** По нему зададим имя, описание, аватар и меню бота через `PATCH /me`. Ник
  `@t603_hakaton_max_bot` выдан организаторами и не меняется.
- **Сервер:** работает по HTTPS на временном домене `45-154-58-251.sslip.io`. Постоянный домен — по желанию, переход
  займёт пару минут (отчёт 0.7). Адрес мини-приложения в настройках бота прописывает Костя.
- **Токен.** Он один на команду, а запущенный экземпляр бота может быть только один. С 27.09 бот работает только на
  сервере, локально — `DEV_MODE` без токена (план до 30.09, раздел 8).
- **Демо и порог 10%.** В демо-доме одному тестировщику не набрать 10% поддержки для требования. Нужно демо-правило в
  Д1, иначе путь A в демо до собрания не дойдёт.
- **Собственный API не заявляем** — уточнить формулировку у организаторов.
- **Каталог `DecisionType`** по ст. 44 и 46 ЖК — сверить с юридическими источниками.
- **Смена секрета HMAC** без потери сопоставления с реестром — открытый вопрос 3 в 04.
