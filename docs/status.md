## Что работает сейчас

- **Запуск:** `docker compose up --build` поднимает базу, бэкенд и Caddy. Сборка образов в CI — 69 с при лимите 300.
  Миграции и демо-дом создаются сами.
- **Бот `@t603_hakaton_max_bot`:**
  - приветствие по ссылке дома `max.ru/<бот>?start=<slug>`;
  - подсказка на любое сообщение;
  - в групповых чатах молчит;
  - `/id` в режиме разработки.
- **Опрос поддержки** (проверен в MAX на десктопе):
  1. Демо-подтверждение собственника.
  2. Инициатива по шаблону «Видеонаблюдение»: форма с проверкой полей (камеры, оплата, доступ к записям), в повестке
     избрание председателя и секретаря, затем камеры (2/3 от всех).
  3. Запуск опроса.
  4. Приглашение в чат с кнопками. Срок показан по времени дома, в тихие часы рассылка ждёт утра, в демо-доме приглашение
     получает только инициатор.
  5. Голос кнопкой или через `PUT /my-vote` с анкетой. После нажатия сообщение показывает голос в м².
  6. Прогресс в м² с порогами 10% / кворум / 2/3.
- **API:**
  - `GET /me`, `GET /houses/{slug}`;
  - собственники квартиры, кандидаты в председатели;
  - `POST /houses/{slug}/demo-membership`;
  - `GET /templates`, `GET /templates/{code}` — шаблоны с формой;
  - `GET /houses/{houseID}/initiatives`, `POST /houses/{houseID}/initiatives`;
  - `GET /initiatives/{id}` — карточка с `allowed_actions` и «моим голосом», в ветке `feat/initiative-read-api`;
  - `POST /initiatives/{id}/start-poll`, `PUT /initiatives/{id}/my-vote`, `GET /initiatives/{id}/poll`.

  Все запросы проверяют подпись MAX, в режиме разработки её заменяет заголовок `X-Dev-User-Id`.
- **Данные и безопасность:**
  - HMAC для телефонов и лицевых счетов, маски ФИО, права на каталоги собственников;
  - точная арифметика долей;
  - итог собрания меняется только один раз;
  - лимиты: тело запроса — 64 КБ, инициатив — 10 в сутки;
  - корень УЦ Минцифры действует только для MAX.
- **CI на каждый пуш:** `gofmt`, `go vet`, тесты с `-race` на PostgreSQL 18, сборка образов.

## Решения и вопросы к команде

- **Название продукта.** По нему зададим имя, описание, аватар и меню бота через `PATCH /me`. Ник
  `@t603_hakaton_max_bot` выдан организаторами и не меняется.
- **Сервер:** VPS в России и домен. Без них нет шагов 0.4 и 0.7.
- **Токен.** Он один на команду, а запущенный экземпляр бота может быть только один. Договориться, кто запускает, и
  спросить организаторов о втором токене для разработки.
- **Срок онлайн-этапа** — уточнить у организаторов.
- **Собственный API не заявляем** — уточнить формулировку у организаторов.
- **Каталог `DecisionType`** по ст. 44 и 46 ЖК — сверить с юридическими источниками.
- **Смена секрета HMAC** без потери сопоставления с реестром — открытый вопрос 3 в 04.
