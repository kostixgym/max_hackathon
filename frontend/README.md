# Мини-приложение

React 19 + TypeScript + Vite. Главный экран `/` показывает профиль MAX (или локальную dev-заглушку), все дома и квартиры пользователя, а также отдельный запуск прикрепления к дому. Invite `start_param` подставляет дом в сценарии прикрепления и сам по себе не создаёт членство.

## Разработка

```bash
npm ci
npm run dev
npm run typecheck
npm run build
```

Vite проксирует `/api` на `http://localhost:8080`. Если backend запущен с `DEV_MODE=true`, создайте `frontend/.env.local`:

```dotenv
VITE_DEV_USER_ID=1001
VITE_DEV_START_PARAM=
VITE_DEV_USER_FIRST_NAME=Анна
VITE_DEV_USER_LAST_NAME=Тестова
VITE_DEV_USER_USERNAME=anna_demo
```

Для Docker Compose те же переменные задаются в корневом `.env`; после изменения выполните `docker compose up -d --build web`. Чтобы проверить прикрепление, задайте `VITE_DEV_START_PARAM` в slug существующего демо-дома или введите его на экране прикрепления. Эти значения используются только локально; для MAX профиль берётся из `initDataUnsafe.user`.

В MAX frontend отправляет `window.WebApp.initData` в заголовке `X-Max-Init-Data`. Все API-запросы проходят через `src/lib/api.ts`.

## Подключённые сценарии

- Вход по ссылке дома и демо-подтверждение квартиры.
- Получение дома и инициатив; список шаблонов и создание черновика по шаблону.
- Запуск опроса, голос собственника, анкета и прогресс в м².
- Демо-доступ сотрудника УК, список организаций и домов.
- Карточка собрания, трекер бюллетеней, отметка получения, ввод решений, предпросмотр и фиксация итога.
- Демо-заполнение бюллетеней и завершение голосования для тестирования собрания.
- Требование в УК: создание, PDF, отметка передачи и кабинет со списком доступных требований.
- Создание собрания сотрудником УК по инициативе на этапе требования.

React MAX UI kit доступен по `/#/ui/kit` (старый адрес `/#/iu/kit` тоже работает). Каталог статичных дизайн-экранов доступен по `/#/__screens`.

Ручная проверка собственника, заявки на подтверждение и PDF-протокол собрания пока не поддержаны backend; интерфейс сообщает об этом вместо фиктивных действий.
